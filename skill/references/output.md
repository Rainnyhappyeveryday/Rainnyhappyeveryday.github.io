# 汇报模板

```
## 本期新增

| 机构 | 方向 | 方式 | 开始 | 人数 | 原文 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

新增 X 条，可看 Y 条；高校索引 83 所，本期有记录 Z 所。

最近截止：
- MM.DD · 机构 · 方向
- MM.DD · 机构 · 方向

线上地址：https://rainnyhappyeveryday.github.io/
```

规则：

- 只放本期新增；存量记录不重复列。
- 没有新增就写「本周无新增」，再给 1–2 条仍开放的存量提示。
- 链接放在「原文」列，用官网地址。
- 不要出现职场字样；用「记录 / 方向 / 机构 / 原文」。
- 线上地址放在最显眼的位置。
